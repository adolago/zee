## Resolution

Confirmed the Zee gateway trusted-proxy boundary behavior is fail-safe:

- Forwarded headers are only honored when the remote socket IP is trusted.
- Untrusted remotes fall back to socket remote address.
- Trusted proxies can forward canonical client IP via `X-Forwarded-For`/`X-Real-IP`.
