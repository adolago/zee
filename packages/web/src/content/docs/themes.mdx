Zee ships with a single built-in theme: `selenized-dark`.

## Default

`selenized-dark` is always used as the built-in default in both TUI and app surfaces.

```json title="zee.json" {3}
{
  "$schema": "https://zee-bot.com/config.json",
  "theme": "selenized-dark"
}
```

## Theme files

Custom theme files are still supported if you explicitly add them:

1. `~/.config/zee/themes/*.json`
2. `<project>/.zee/themes/*.json`
3. `./.zee/themes/*.json`

## Note

If you previously used legacy keys like `opencode-theme-id`, Zee reads them as a fallback, but new writes use `zee-theme-id`.
